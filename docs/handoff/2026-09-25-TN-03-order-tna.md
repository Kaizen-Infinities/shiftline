# TN-03 — Export order time-and-action (T&A) calendar

Spec: `docs/research/tamil-nadu/market-and-features.md`, "BUILD NOW 3: TN-03".

## Shipped

- **Schema**: `OrderTna` (`@@unique([companyId, tnaNo])`, FK `Customer`, optional
  `salesOrderId` Int checked tenant-scoped) and `OrderTnaMilestone` (`@@unique([tnaId, seq])`,
  cascade from the plan). Migration `20260925030000_order_tna` has RLS (`tenant_isolation`,
  `platform_bypass`) and audit triggers; both models are in `AUDITED_MODELS`.
- **Calc** (`order-tna.calc.ts`, pure): the four templates as a code constant (`GARMENT_KNIT`,
  `HOME_TEXTILE`, `LEATHER_FOOTWEAR`, `GENERIC`), planned date = ex-factory − offset clamped to the
  order date, reschedule that shifts only `PENDING` milestones, delay days, and RAG (red when a
  pending milestone is past due, amber within 3 days).
- **API** `/api/order-tna` behind `authMiddleware`, `requireFeature("production")` and
  `order-tna.*` permissions: `GET /templates`, `GET /` (rag, next milestone, overdue count),
  `POST /`, `GET|PATCH /:id` (ex-factory shift in one transaction; `status CANCELLED` instead of
  delete), `POST /:id/milestones` (seq = max + 1), `PATCH /:id/milestones/:milestoneId` (DONE needs
  `actualDate`), `GET /alerts?days=3` (ACTIVE orders only). No DELETE.
- **Registries**: permission module `order-tna` (view/create/edit/delete/export), added to the
  `production` feature and to the PRODUCTION role template in provisioning; `API_PATHS.orderTna`.
- **Web**: `/production/order-tna` (`OrderTnaPage.tsx`), sidebar entry under Transactions →
  Production, smoke line. Alerts strip, active-order list with RAG dots and buyer filter, detail
  panel with milestones (mark done with actual date, reopen, delay in red) and reschedule.
- **Tests**: `test/unit/order-tna.spec.ts`, `test/integration/order-tna.spec.ts` (happy path,
  every validation rejection, 409 duplicate, 403 for the accounts role, foreign company sees
  nothing). `leak.spec` lists both models as seedless (covered by the cross-tenant test).

ex-factory date, see red/amber/green slippage at a glance, and move the ex-factory date without
