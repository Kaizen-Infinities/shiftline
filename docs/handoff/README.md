# Hand-off notes

One file per work package, named `YYYY-MM-DD-<package>.md` (for example `2026-09-06-P0-00-import.md`).
Each note answers three questions in under a page:

1. What shipped, with the PR link and how it was verified.
2. What is half-done, with the exact file and the next step.
3. What is blocked on a person, an account or a decision.

A new session starts by reading the latest note here and `CLAUDE.md`.
