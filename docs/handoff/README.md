# Hand-off notes

Notes up to 2026-09-29 are in [`docs/archive/handoff/`](../archive/handoff/). They are historical.

One file per work package, named `YYYY-MM-DD-<package>.md`. Each note answers three questions in
under a page:

1. What shipped, with the PR link and how it was verified.
2. What is half-done, with the exact file and the next step.
3. What is blocked on a person, an account or a decision.

Each package still adds a note here and updates [`docs/STATUS.md`](../STATUS.md) and
[`docs/ROADMAP.md`](../ROADMAP.md).

A new session starts by reading `docs/STATUS.md`, the newest note here if any, and `CLAUDE.md`.
