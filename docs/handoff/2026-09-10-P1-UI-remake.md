# P1-UI — Tailwind frontend remake foundation

## Shipped

- Removed Bootstrap and React Bootstrap from the web workspace and migrated their remaining
  consumers to repository-owned Tailwind layout, card, form, table, feedback, and dialog
  primitives without changing page handlers or service contracts.
- Removed origin branding from runtime assets and retained tenant-driven logos and favicons.
- Established the route-group inventory; no group is complete until every contained screen has been individually rebuilt and browser-reviewed.
- Hardened the responsive shell with a skip link, semantic main landmark, 400 px-safe gutters and
  footer, and locally scrollable dense tables.
- Made mobile navigation a labelled modal drawer with an explicit close control, Escape and
  backdrop dismissal, focus containment and restoration, scroll locking, route-change dismissal,
  and accurate expanded state on its trigger.
- Preserved permission-filtered navigation, protected/super-admin route boundaries, entitlements,
  API and authentication paths, tenant socket updates, themes, and Indian formatting.

## Half-done / known gaps

- The source and production build were verified locally. Browser-backed screenshots could not be
  captured because the Playwright Chromium executable is absent from the execution image.
- Authenticated smoke execution additionally requires the API, PostgreSQL, and seeded accounts.
