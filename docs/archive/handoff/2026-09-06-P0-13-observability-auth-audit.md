# P0-13 — Observability, backups, audit trail base, auth hardening

## Shipped

- pino structured logging with request ids (`x-request-id` in, out, in error bodies, in every
  log line and audit row); all 132 `console.*` calls in the API rewritten; `no-console` is an error.
- `GET /health`, `GET /ready` (db, migrations, worker heartbeat); optional Sentry via `SENTRY_DSN`.
- Daily `pg_dump` job (01:30 IST) with rotation and `backup_runs` history, `scripts/backup.sh`,
  `scripts/restore.sh`, platform-admin endpoints, restore drill recorded (0.3 s / 2.2 s).
- 15-minute access tokens, rotating httpOnly refresh cookie with reuse detection, sliding
  7-day / absolute 30-day sessions, device clients get the token in the body; web app holds the
  token in memory and refreshes silently (axios, RTK Query, timer). Playwright login test now
  reloads the page to prove the cookie path.
- Append-only audit trail by database trigger on 28 books, document, payroll and master tables
  (generated by `scripts/gen-audit-migration.ts`); `audit_log` refuses UPDATE/DELETE except
  from the retention sweep; actor, request id and impersonator flow through transaction-local
  settings written by `lib/prisma.ts`.
- `npm audit` gate with an expiring allowlist in the static CI job; ASVS L2 checklist and
  pentest scope under `docs/security/`.
- 101 API tests, 14 browser tests green.

## Half-done / known gaps

- Payslip, BankAccount and OpeningBalance are not models yet; add them to `AUDITED_MODELS` and
  regenerate the audit migration when P1-08/P1-16/P1-20 create them.
- The audit trigger records `roleId` only as the entity id for `role_permissions` (composite
  key); the row JSON carries both ids.
- Sentry is wired but unverified against a real DSN (none available locally).
- Two accepted advisories expire 2026-12-31: deepmerge-ts via the Prisma CLI (upgrade to Prisma 8
  planned with P1-00) and uuid via imagekit (replace imagekit in P1-03).
- `/ready` reports the worker as `unknown` until the first heartbeat completes in that database.
- TLS, HSTS and a secret store wait for the hosting decision.
