# Phase 2 — the plan and the build order

Phase 1 closed on 2026-09-12 (`2026-09-12-phase-1-complete.md`). Phase 2 is the set of gaps that
note and the per-package notes carried forward: the things that are computed but not wired, the
work that should schedule itself and does not, and the reports the inspector asks for. Nothing
here needs an account the owner has not supplied; the live-adapter work (Razorpay, MSG91, GSP)
stays blocked and is out of Phase 2.

Each package below is built by its own agent on its own branch off
`claude/sonnet-agents-phase-2-zodoon`, then merged in the order listed. Every package follows the
loop in `CLAUDE.md`: spec in `docs/specs/P2-xx-*.md`, schema and failing tests, implement,
self-review, hand-off note in `docs/handoff/`.

## Coordination rules for the agents

- Shared files that every package touches (`schema.prisma`, `permissions.ts`, `features.ts`,
  `api-paths.ts`, `index.routes.ts`, `jobs/index.ts`, `sidebar.data.ts`, `smoke.spec.ts`,
  `leak.spec.ts`, `provisioning.service.ts` ROLE_DEFS): add lines, never reorder or reformat.
- Migration folders are named `202609140N0000_<package>` where N is the package number, so
  they sort in build order after merge.
- Each agent runs its tests against its own database (`TEST_DATABASE_URL` with a distinct name)
  so suites do not clash on the template database.
