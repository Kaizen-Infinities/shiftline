# P1-08 part C — GST on the web

## Shipped

- Configuration → GST & HSN (`/settings/gst`): HSN/SAC codes (search, type filter, add/edit,
  deactivate/remove, reactivate) and GST slabs, behind `gst_tax.*`.
- GSTIN per place: company settings gains a Places of business table (GST state and GSTIN per
  place), the onboarding GST step a Branch GSTIN per non-head-office place; the company API accepts
  `businessPlaces[].gstin`.
- Sales invoice form: state-code supply type, document-type badge, HSN column from the product
  master, product/HSN rate default, zero tax for composition or unregistered companies, and the
  number assigned by the server's series (preview via `GET /documents/next-number`).
- GRN form: state-code supply type, HSN column, reverse-charge switch, series number preview.
- Printed invoice and GRN: document type title, place of supply, reverse charge, HSN column, split
  by the stored supply type.
- Returns: kind selector (goods return / price adjustment), credit/debit note number, kind and GST in
  lists and detail views.
- API: `/documents/next-number`, HSN on product and raw-material responses; routes snapshot updated;
  the GST documents numbering test covers the endpoint (150 API tests).
- CI: Docker cache export failures (`error writing layer blob: not_found`, a GitHub cache outage
  on run 20) no longer fail the images job (`ignore-error=true`).

## Half-done / known gaps

- The sales invoice form still keeps the invoice-settings prefix screen alive for display; the
  series is authoritative now. Retire `InvoiceSetting.formatTemplate` with the numbering settings
  screen in P1-09.
- The customer, supplier, product and raw-material forms do not yet offer an HSN picker or the
  registration type; masters are set through the API/CSV import (customers derive registration and
  state from the GSTIN). A small HSN lookup field on the product forms is the next web touch.
- Expense and petty-cash screens do not yet show the GST/TDS fields added in part B.
- Company settings does not add or remove places; that stays in the onboarding wizard.
