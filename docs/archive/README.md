# Archive

These files are historical and not current. Do not plan, test or design from them.

For the present, read:

- [`docs/AS-BUILT.md`](../AS-BUILT.md), what is live and was seen running.
- [`docs/STATUS.md`](../STATUS.md), the current state.
- [`docs/ROADMAP.md`](../ROADMAP.md), what to build next.
