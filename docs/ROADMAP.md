# Roadmap

Ideas that are not built yet and are worth building. An idea is here only if it is absent from the code, fits [no hidden books](decisions/2026-09-14-no-hidden-books.md), and has a stated reason: compliance-mandatory, buyer or OEM requirement, cash, or plant cost. Ids are `R-01`, `R-02`, and so on; never reuse the old `P2-xx` ids, which collide. A package starts by writing `docs/specs/R-xx-<name>.md`. Sizes: S up to 2 days, M 3-5 days, L 1-2 weeks. "Source" links are to archived material, for detail only; check the code before relying on them. Current state is in [STATUS.md](STATUS.md) and [AS-BUILT.md](AS-BUILT.md).
