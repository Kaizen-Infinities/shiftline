# P0-05 — CI (F2)

**Goal.** Every pull request is typechecked, linted, schema-validated, tested against a
real PostgreSQL and built before a human reviews it.

**Workflow `.github/workflows/ci.yml`.** Jobs: `static` (typecheck, lint, prettier on new
code), `migrations` (Prisma validate; `migrate deploy` + `migrate diff --exit-code` gate
once P0-06 lands the initial migration, `db push` fallback until then; grep gates for
`db push` in scripts, `new PrismaClient` outside the shared client, session-scoped
`SET app.*`), `test-api` (Postgres service container, `TEST_DATABASE_URL`), `test-web`
(tests + Vite build), `e2e` (placeholder until P0-12), `docker` (api and web images built
with layer cache on pushes to `main`; nothing is published).

**Repo hygiene.** Dependabot (npm grouped, actions, docker), CODEOWNERS for filing /
payment / tenancy / auth paths, PR template with the definition-of-done checklist,
`docs/runbooks/repo-setup.md` for branch protection.

**Done when.** The workflow is green on this branch's next push; the four required checks
are configured in branch protection (your step).
